# Наскрізний проєкт з дисципліни «Вебтехнології та вебдизайн»
Автор: Гнатюк Владислав, група 5-ІПБ
Тема: Електронна бібліотека «BookSpace» — вебзастосунок для каталогізації, пошуку та збереження електронних книг і навчальних матеріалів.
Стек: React + PHP + MySQL

## Робота зі стилями
```bash
npm install            # встановити Sass
npm run css            # компіляція SCSS → CSS у режимі watch
npm run build:css      # стиснена збірка без source map
```
Демонстрація компонентів: `ui-kit.html`. Технічне завдання: `docs/tz.md`.
